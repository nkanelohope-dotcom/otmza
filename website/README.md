# On The Move ZA — Professional Website

A complete, responsive multi-page website for **On The Move ZA** — professional cleaning, packing, moving and home setup services in Johannesburg & Pretoria.

## Pages Included

| File | Description |
|------|-------------|
| `index.html` | Home page with hero, service overview, why us, CTA |
| `about.html` | Company story, vision, values, social impact |
| `services.html` | Full service catalogue (cleaning, specialised, packing/moving) |
| `pricing.html` | All pricing tables with tabbed interface |
| `partners.html` | Estate agency & property manager partnership page |
| `gallery.html` | Image gallery of services and promo material |
| `contact.html` | Contact details + enquiry form (opens WhatsApp) |
| `book.html` | Booking form with steps (opens WhatsApp) |

## Features

- Fully responsive (mobile, tablet, desktop)
- Sticky navigation with mobile hamburger menu
- WhatsApp integration on forms and floating button
- Tabbed pricing panels for easy navigation
- Brand colours (green + yellow) matching company identity
- All contact details, social links and service pricing from provided materials

## How to Use / Deploy

1. Open `index.html` in a browser to preview locally.
2. Upload the entire `otmza-website` folder to any web host (Netlify, Vercel, cPanel, GitHub Pages, etc.).
3. No build step required — pure HTML, CSS and JavaScript.

## Customisation Notes

- Update phone numbers, email or social links in the footer of each page (or centralise later with a template).
- Replace or add images in the `images/` folder.
- Pricing is current as of the provided menus; edit `pricing.html` when rates change.
- Forms currently open WhatsApp with a pre-filled message. For a backend form handler, connect to a service such as Formspree or Netlify Forms.
